# Blue Team Labs

Hands-on Blue Team lab notes and exercises covering practical SOC analyst skills including SIEM alert triage, Windows event log analysis, PCAP investigation, phishing analysis, and MITRE ATT&CK mapping.

Content is written in personal notes format based on practical exercises from TryHackMe, LetsDefend, and Blue Team Labs Online. No copyrighted content or paid platform solutions are included.
