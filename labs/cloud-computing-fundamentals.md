# Cloud Computing Fundamentals

## Overview
Completed the Cloud Computing Fundamentals room on TryHackMe ☁️🔐

This room provided a practical introduction to understanding cloud computing fundamentals and how it helps businesses build more flexible, scalable, and cost-efficient services.

## Key Concepts Learned

### 1. Introduction to Cloud Computing
- Concept of cloud computing and its importance
- Understanding how cloud transforms modern IT infrastructure
- Benefits of cloud adoption for organizations

### 2. Cloud Service Models
- **IaaS (Infrastructure as a Service)**: Control over virtual servers, storage
- **PaaS (Platform as a Service)**: Development platform without infrastructure management  
- **SaaS (Software as a Service)**: Ready-to-use applications
- When to use each model appropriately

### 3. Cloud Deployment Models
- **Public Cloud**: Shared resources, cost-effective, highly scalable
- **Private Cloud**: Dedicated resources, more control, enhanced security
- **Hybrid Cloud**: Combination of public and private clouds

### 4. Core Cloud Benefits
- **Scalability**: Scale resources up or down based on demand
- **High Availability**: Services remain accessible with minimal downtime
- **Global Access**: Resources accessible from anywhere
- **Pay-as-you-go**: Only pay for what you use
- **Efficiency**: Reduces costs and complexity

### 5. AWS EC2 Basics
- Introduction to EC2 (Elastic Compute Cloud)
- Understanding instance types and their use cases
- Deploying cloud instances
- Cost optimization through stopping unused resources

## Connection to Cybersecurity

This room provided a strong foundation for understanding the relationship between Cloud Computing and Cybersecurity, including:
- How cloud security differs from traditional infrastructure security
- Shared responsibility model in cloud security
- Importance of proper cloud configuration
- Security considerations when deploying cloud resources
